# ADB-Tools

A helpful tool to interact and carry out common tasks with ADB. Especially helpful when you have multiple devices connected.

## Features

- Install APK
- Run [scrcpy](https://github.com/Genymobile/scrcpy)
- Display device info
- Screenshot device
- Setup wireless ADB and connect to device
- Tab completion (Press `<TAB>`)

## Install

```bash
cd adb-tools
chmod +x ./install.sh
./install.sh
```

## Usage

### CLI Mode

```bash
adb-tools <command>
```

### TUI Mode

```bash
adb-tools
```
